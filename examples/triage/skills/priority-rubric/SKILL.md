# Priority rubric

A request is **urgent** when it names any of: a deadline inside three working
days, money taken for something not delivered, an account nobody can sign in
to, or anything unsafe.

A request is **routine** for everything else, including billing questions,
plan changes, feature requests, and how-to questions.
