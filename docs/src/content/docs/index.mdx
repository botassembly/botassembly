<div class="ba-story">
	<section class="ba-story__card">
		<h2>Who it is for</h2>
		<p>You own the work and you do not write code. You describe the procedure step by step, the way you would hand it to a new colleague. The work runs on its own, it repeats, and it waits for nobody.</p>
	</section>
	<section class="ba-story__card">
		<h2>What it is</h2>
		<p>An assembly is a folder of plain files. It tells agents what to do, one step at a time. A runtime is the program that executes such a folder. It walks the folder, runs the checks you wrote, and writes down what happened.</p>
	</section>
	<section class="ba-story__card">
		<h2>Why it holds</h2>
		<p><strong>Understandable.</strong> A person reads the instructions and the record without installing anything. <strong>Durable.</strong> The files live in git and outlive the program that ran them. <strong>Portable.</strong> The format names no program.</p>
	</section>
