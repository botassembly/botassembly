## Where to go next

<CardGrid>
	<Card title="The specification" icon="open-book">
		The format is written down one document per part: the folder layout, a stage's options, the three checks, slots, the graph, and the record. Beside it sit 143 conformance cases. Each case names a command and the exact output it must produce, so a runtime either accepts the folder or refuses it for a stated reason.

		[Read the specification](/specification/overview/) · [Conformance](/specification/conformance/) · [The principles](/principles/)
	</Card>
	<Card title="The runtime" icon="rocket">
		`bot` is one implementation of that format. `bot assembly check` resolves every stage and refuses a bad folder without calling a model or spending money. `bot run start` calls the provider you configured and seals the record. The format and the runtime carry separate version numbers.

		[Install and run one](/guides/first-assembly/) · [Operating runs](/guides/install-and-use/) · [Format and runtime](/format-and-runtime/)
	</Card>
	<Card title="The use cases" icon="puzzle">
		Four folders of everyday knowledge work, each one a step up. `hello` greets a new teammate in one stage. `triage` sorts a customer request into urgent or routine, and the walkthrough above builds it. `brief` turns a week of team notes into a digest, fanning out and looping. `outline` plans a report from a rough topic by calling itself.

## What it is not

<Aside type="caution" title="Know this before you pilot it">
	**Not a sandbox.** Commands, hooks, gates, and subprocesses use your filesystem and network authority. Contain an untrusted folder with the operating system or a container.

	**No run-wide budget.** A stage carries a timeout and concurrency has a width. Nothing bounds a run as a whole: no deadline, no cost budget, no disk cap.

	**Pre-1.0.** Assembly and record contracts may change without migrations before 1.0. Version 1.0 is the first promised compatibility boundary.

	**Linux only.** Linux with Node 22.22 or newer is the supported platform, because the checks prove it there. macOS may work and is not verified. Windows is not supported.
</Aside>
