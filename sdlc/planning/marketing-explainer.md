# Marketing: the HTML explainer (parked goal)

Recorded 2026-08-07 from Ian. Promotion is a first-class goal for
botassembly: anyone should be able to pick it up, and the pitch has
to make it feel simple.

The vehicle: a set of single-file HTML explainer pages in the style
of the html-effectiveness repo (`~/foss/html-effectiveness`) — deep
concepts explained with basic web technology, polished and pretty.
The old archive repo's `html-docs` skill
(`~/fable/bot-2026-archive/.agents/skills/html-docs/SKILL.md`)
captures the authoring-then-critique loop to rebuild.

Pages the explainer set should cover:

- what an assembly is (the specs, in plain terms)
- features and functions of the bot runtime
- the benefits — why this over ad-hoc agent scripts
- the queue: tickets, channels, dispatch
- the observability dashboard
- SDLC as the worked example of all of it together

Shared visual language lives in the dashboard repo's
`sdlc/planning/style-guide.md` (palette and techniques harvested from
the old experiment and html-effectiveness). Not scheduled; this file
exists so the goal is not lost.
