# Legacy tickets (archived)

The repo's pre-sdlc tickets, numbered 0001-0169 on their own
counter, used to live here. They are history, not work, and their
bodies were removed from the working tree in the 2026-08 planning
cleanup — read them with `git log -- sdlc/planning/archive/tickets`
if you need one. The live ticket system is `sdlc/tickets/` — the
legacy numbers collide with it, and on 2026-08-13 a flight was
judged against the wrong 0032 because this folder still answered
to the name "tickets". Nothing may treat this folder as a ticket
source. The retrospective and review files kept beside this README
are the era's summary, not tickets.
