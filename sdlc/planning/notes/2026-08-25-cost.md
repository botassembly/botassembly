## The structure of cost today

Both day-to-day providers run on subscriptions (opencode-go / deepseek-v4-flash and openai-codex / gpt-5.6-luna), so the marginal token price is zero until a subscription exhausts — and exhaustion does happen mid-day, which stops work without costing money. That makes the scarce resources: subscription headroom, wall-clock, and disk — not dollars per token.

## Point observations (append, never rewrite)

- 2026-08-25: the spec pressure test spent ~3.2M subagent tokens across five probes plus verification (`reports/pressure-test-2026-08-25.md`).
- 2026-08-25: a single build-flow stage turn observed at ~87k total tokens (a dispatcher repair stage, `bot show`).
- Records carry per-stage token attribution (botassembly 0122's `--usage`), so per-run cost is answerable from the machine; per-campaign cost needs a stats verb in a downstream dashboard before it is one command.
