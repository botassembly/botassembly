# The specification and the runtime now say the same thing

The audit found twelve contradictions between the specification and the runtime. Nine moved the specification: exit codes 3, 4, and 5 in `runtime.md` and invariant 23; the agent's `/tmp/bot-<hash>` handle; the stale three-standing sentence in `auth.md`; the `home.md` reconciliation; two names for the two stem rules; the stdin-writing sentence replaced with immediate EOF; and the `$TMP` warning placed where `gating.ts` places it. Three moved the runtime, naming this ticket. C4 made `flowBody` admit a `DESCEND.md` body, because `descend.md` already calls the flow otherwise ordinary; a body authors wrote and never saw now reaches every stage's prompt, and a whitespace-only one still stays silent. C5 made `parseFanout` pass an empty option-name list, so `timeout`, `retries`, `local-context`, and `intelligence` on `FANOUT.md` now draw `key-unknown` instead of being silently dropped. C9 made `markTool.execute` reject whitespace-only evidence the way it already rejects an empty skip reason. C12 landed in ticket 0281; the rest of this list is 0282's.

A closed error code and cause vocabulary now lives beside `REFUSAL_CODES` in `bot/src/spine.ts`: `ERROR_CODES` and `ERROR_CAUSES`, eight codes and 158 causes. Every `CliFailure` draws from it, and `spec-error-vocabulary.test.ts` pins the specification to it both ways, a declared code the specification omits is red and a specified code the runtime does not declare is red. The JSON error envelope this vocabulary fills is now documented in `inspection.md`. Exit codes 4 and 5 are specified. The 4,194,304-byte (4 MiB) request ceiling and its refusal are documented in `invocation.md`, both for a fresh request and for resume. The `--correlation` option and its 256-byte bound are documented. Timing constants — the 250 ms grace, the 1 s and 5 s drain with its terminal fault, and the 250 ms `$TMP` cadence — are documented. The credential names this runtime scrubs before a child sees them are pinned both ways by `spec-credential-names.test.ts` against `CREDENTIAL_ENVIRONMENT_NAMES`, and other previously unspecified options and bounds are written down alongside them. The `model-unresolved` runtime-only exemption is now one sentence in `refusals.md`, and `conformance.test.ts` derives its exemption list from that sentence instead of carrying a literal array. Stale witnesses in the ledger are repaired.

The version statement now says this publication is unreleased and targets `0.1.0` as the first public release. The three places that enforced the old `0.0.1` string moved: `PUBLICATION_VERSION` in `spec-publication.test.ts`, the hardcoded conformance count in `conformance.md`, and the version sentence in the repository `README.md`. `bot/package.json` is untouched; the release ticket owns it. An honesty paragraph now says what the private-file check does not do: no `O_NOFOLLOW`, no ancestor-directory check, a same-account replacement still possible.

Implementation found three audit assumptions the specification carried were wrong. No `bot assembly create` command exists; `specification/README.md` and `CHANGELOG.md` named it in error. The scrubbed-credential list is 52 names, not the eight the audit assumed. Hooks do receive `TMPDIR`; the audit's contrary claim was itself wrong, and `runtime.md` now says so beside `$TMP`.

Independent design review accepted the contract after one rejection. Independent code review accepted the implementation after one round of must-change findings: an unpinned credential name list, retired-command anchors in the CHANGELOG pointed at live targets instead of their replacements, and an exemption regex broader than the one runtime-only code it was meant to cover.

The complete local gate passed on the rebased commit: `make check` exited 0 with 214 test files, 1,723 tests, all 143 conformance cases, and static checks. The ratchet moved from 18,524 to 18,733 nonblank lines. Hosted runtime run `34844488159` and hosted docs run `34844488471` both passed on commit `a0ad347`.

Two limits stay open. Thirty-eight of the fifty invariants still have no corpus case; only the twelve this ticket and 0281 touched gained one. The `0.1.0` target is Ian's to overturn. G4 and G5 stay excluded from the witness-ledger repair: a model-free static corpus cannot witness a runtime-only invariant, and the ledger already admits the code-versus-rule limit it would otherwise restate.
