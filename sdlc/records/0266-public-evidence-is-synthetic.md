The public tree no longer contains the transformed triage provider record or its provider-produced output. The README, draft blog, example guidance, and home-page walkthrough no longer quote or claim real-run evidence. The durable publication decision now forbids publishing provider records and sessions. The conformance text explicitly identifies its frozen record as authored synthetic data.

The walkthrough uses one labeled synthetic 22-event illustration derived from the checked-in assembly topology. It contains no provider-derived timestamps, hashes, identifiers, provider or model facts, token counts, timings, byte counts, or output prose. Independent provenance review compared it with both removed artifacts and accepted every admitted fact. The checker pins that fixture and the invented conformance record by exact path and SHA-256.

It rejects retained-run paths, record and session basenames, Bot record sequences, and both Pi session forms regardless of neutral names, unrelated directories, tests, historical records, case changes, Markdown wrapping, or JSON fences. Generic binary assets remain unparsed. Independent code review rejected the first path-limited scanner; the accepted remediation closed every reproduced bypass.
